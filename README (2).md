# 📊 Customer Churn Analysis

## 📌 Project Overview

This project analyzes customer churn data to understand customer behavior, subscription patterns, and customer support interactions.

The project uses Python, Pandas, NumPy, SQLite, Matplotlib, and Seaborn for data extraction, cleaning, transformation, exploratory data analysis, and visualization.

The workflow starts with customer data stored in an Excel workbook, converts the Excel sheets into SQLite tables, loads the data into Pandas DataFrames, performs data cleaning and feature engineering, combines customer, subscription, and support information, and analyzes churn patterns.

---

## 🎯 Objectives

- Analyze customer churn and retention.
- Clean and standardize customer data.
- Combine customer, subscription, and support datasets.
- Calculate important customer metrics.
- Analyze churn patterns across plans and states.
- Analyze customer complaints and escalations.
- Examine the relationship between support interactions and churn.
- Categorize customers based on churn risk.
- Create visualizations to understand customer behavior.
- Practice SQL operations using SQLite and Python.

## ⚙️ Feature Engineering

### Churn Flag

A `churn_flag` is created to identify whether a customer has churned.

- `1` = Customer churned
- `0` = Customer did not churn

Example:

```python
df_db_subscription['churn_flag'] = np.where(
    df_db_subscription['cancellation_date'].notna(),
    1,
    0
)
```

### Complaint Count

The project calculates the number of complaints associated with each customer.

### Customer Tenure

Customer tenure is calculated using subscription dates.

### Churn Risk

Customers are categorized based on their churn score into different risk levels.

## 🗄️ SQLite & SQL

SQLite is used to store the Excel datasets as database tables.

The notebook:

1. Reads the Excel workbook.
2. Creates a SQLite database.
3. Converts Excel sheets into SQLite tables.
4. Retrieves table names using SQL.
5. Loads SQL tables into Pandas DataFrames.
6. Performs SQL-based analysis.

This demonstrates how Python can be integrated with a relational database for data analysis.
